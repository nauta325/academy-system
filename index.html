⚠️ 거의 다 왔어요 — 한 칸만 바꾸면 됩니다

배포는 됐는데 Vercel 이 엉뚱한 폴더를 보고 있습니다. 화면 파일은 전부 attendance-report 안에 있어요.

  1. Vercel 에서 이 프로젝트 → Settings
  2. Build and Deployment (또는 General) 에서 Root Directory 찾기
  3. ./ 로 돼 있는 걸 아래로 바꾸고 Save attendance-report
  4. Deployments 탭 → 맨 위 배포의 ⋯ → Redeploy
    설정만 바꾸면 안 바뀝니다 — Redeploy 를 꼭 눌러야 새 설정으로 다시 짓습니다.
✅ 제대로 되면 1~2분 뒤 이 주소에 화면 버튼 4개가 있는 홈이 뜹니다. 그 다음 Settings → Environment Variables 에서 SUPABASE_URL · SUPABASE_SERVICE_KEY 두 개만 넣고 또 한 번 Redeploy 하세요. (환경변수는 이미 배포된 것에는 적용되지 않습니다)
왜 이 안내가 보이나 — 이 글이 보인다는 건 Vercel 이 저장소 맨 위를 띄우고 있다는 뜻입니다. 맨 위에는 설명 파일만 있고 화면 파일이 없어서, 원래라면 영어로 된 「This page doesn't exist」 404 가 떴을 자리예요. Root Directory 를 제대로 넣으시면 이 페이지는 다시 보이지 않습니다.
