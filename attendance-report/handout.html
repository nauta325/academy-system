PART ONE
셋업 — 30분이면 내 주소가 생깁니다
00
오늘 만드는 것
한눈에 보는 올인원 7기능
1
데일리 리포트 (작성·보내기)

학생별로 진도·태도·과제·단어테스트를 작성. 진도는 교재 목차의 다음으로 자동 전환(바뀐 날만 수정) → 완료되면 학부모에게 카톡 발송.

2
출결 키오스크

학생이 PIN 4자리만 누르면 등원/하원 자동 기록. 예정 시간보다 늦으면 지각 자동 판정.

3
출결 현황판

오늘 누가 왔고(등원·곧 하원·하원), 안 왔는지(미등원) 실시간. 카드 터치로 하원 처리·미등원 알림톡.

4
월말평가서 (AI)

월 선택 → 통계 자동 집계 → 클로드가 평가서 본문 작성 → 수정 → 저장 → 학부모 링크.

5
선생님앱

내 담당 학생만 보이는 현황판 + 과제 내주기. 「진도로 채우기」를 누르면 오늘 진도가 과제 제목에 자동으로 들어갑니다.

6
학생앱

학생이 폰으로 들어와 오늘 과제를 체크. 내 진도·최근 수업기록·월말평가서도 봅니다. 로그인은 학생ID + 출결번호(키오스크 번호 그대로).

7
카카오 알림톡 (선택)

등원·하원·미등원·데일리 리포트·월말평가서 링크를 학부모에게 자동 발송. 솔라피 검수가 필요해서 준비된 분만 후반부에 연결합니다. 알림톡 없이도 나머지는 전부 됩니다.

스택 한 줄
Supabase가 데이터, Vercel이 서버, Claude가 개발자. 데이터 입력은 최소로 — 출결은 터치, 진도는 하원할 때 한 줄.

02
Supabase — 데이터베이스
SQL 붙여넣기 딱 한 번
A
프로젝트 만들기
  • supabase.com 로그인 → New project.
  • 이름·비밀번호(Database Password) 정하고 Create. 1~2분 기다립니다.
B
테이블 만들기 — SQL 1번
  • 왼쪽 메뉴 SQL Editor → New query.
  • 복제한 리포의 sql/setup.sql 파일을 열어 전체 복사.
  • SQL Editor에 붙여넣고 오른쪽 아래 Run. → 표(테이블) 6개 + 샘플 학생·기록·과제가 한 번에 생성됩니다.
✓ 이게 앱스크립트판의 "노션 DB 5개 수작업 + 속성명 일치 지옥"을 대체합니다. 속성명 오타로 나던 is not a property 에러가 원천적으로 사라져요.
C
열쇠 2개 복사 (다음 단계에서 씀)
  • 왼쪽 Project Settings → API 로 이동.
  • Project URL 복사 → 메모 (SUPABASE_URL).
  • service_role 키 복사 → 메모 (SUPABASE_SERVICE_KEY). 비밀키니 남에게 공유 금지.
⚠️ service_role 키는 비밀입니다
이 키는 Vercel 환경변수에만 넣고, 채팅·화면·깃허브에 절대 붙여넣지 마세요. (서버만 사용)

출결 현황판 /board.html — 오늘 등원 · 곧 하원 · 하원 · 미등원이 상단 요약과 카드로 한눈에.

데일리 리포트 /daily.html — 오늘 등원을 판단해 다음 진도를 적용한 리포트가 자동 생성됩니다.

  • 학생별로 진도(직전 수업과 비교 표시) · 태도 · 과제 · 단어테스트(결과+점수)를 작성. 칸을 고치면 자동 저장.
  • 추가사항은 학부모 카톡에 나가고, 지적사항은 내부 기록용(학부모에게 안 나감).
  • 다 쓰면 📨 리포트 카톡 보내기 → 대상·내용을 미리 확인하고 선택 발송(알림톡 설정 시).
✓ 매일의 데일리 리포트가 월말평가서의 재료입니다. 진도가 자동으로 굴러가니 밀리지 않아요.
★
교재 목차 = 진도 자동 전환 (데일리리포트가 쉬워지는 핵심)

데일리리포트가 매일 생겨도 진도를 손으로 못 채워서 밀리는 게 가장 큰 문제였죠. 그래서 교재 목차를 순서대로 한 번 넣어두면, 매일 진도가 다음 목차로 자동 전환됩니다.

  • /books.html 교재 관리에서 교재별 목차를 붙여넣기(한 줄에 하나). 교재명은 학생 교재명과 똑같이.
  • 속도는 교재별 하루 진도(유닛 수)로: 1=매 수업 한 유닛, 2=두 유닛씩.
  • 복습은 목차에 "복습 Unit 1~4" 같은 줄을 끼워 넣으면 그 날 복습에서 머뭅니다(코드 수정 없이).
  • 매일 새벽 데일리 리포트가 자동 생성될 때, 진도가 다음 단계로 이미 채워져 나옵니다(따로 누를 필요 없음). 그날 다르게 나갔으면 그 학생만 수정.
✓ 진도를 매일 안 써도 되니 데일리리포트가 안 밀리고, 그게 쌓여 월말평가서가 굴러갑니다.

월말평가서
AI 생성 → 학부모 링크

/report.html(선생님) → /parent.html(학부모).

  • 월을 고르고 불러오기 → 학생별 통계(수업일수·단어통과율·과제율)가 뜹니다.
  • AI 평가서 생성 → 클로드가 쓴 본문 확인·수정 → 저장.
  • 학부모 링크 복사(학생별) 또는 상단 열람 링크 목록(전체)으로 전달. 알림톡 설정 시 미전송분 자동 발송.
  • 학부모는 받은 링크로 자기 아이 것만 열람 (월별 이력 포함).

바이브 코딩
코드 안 열고, 말로 바꾼다

바꾸고 싶은 게 생기면 클로드(웹)에 내 리포를 연결하고 아래처럼 말하면 됩니다. 클로드가 코드를 고치고 푸시하면 몇 분 뒤 내 사이트에 반영돼요. 아래 문장을 그대로 복사해서 시작해보세요.

① 평가서 어투 바꾸기
월말평가서 어투를 더 따뜻하고 구체적으로 바꿔줘. 그리고 3문단으로 써지게 해줘. lib/claude.js 의 프롬프트를 고치면 돼.
② 현황판 지각생 강조
출결 현황판에서 지각한 학생 카드는 노란색 배경으로 눈에 띄게 표시해줘. board.html 을 고치면 돼.
③ 우리 학원 요일 추가
우리 학원은 토요일도 수업해. 학생 관리 화면과 출결 판정에 토요일을 추가해줘.
④ 미등원 판정 시간 조정
미등원 알림은 예정 등원시간에서 20분 지난 뒤에 뜨게 바꿔줘. 지각 유예도 20분으로 맞춰줘.
⑤ 과목 추가 (수학)
우리 학원은 수학도 가르쳐. 학생 교재·진도에 수학 과목을 추가해줘. 데이터는 jsonb라 스키마는 안 바꿔도 될 거야.
막히면 그대로 물어보세요
에러가 나면 에러 메시지를 통째로 복사해서 클로드에게 붙여넣고 "이 에러 고쳐줘"라고 하면 됩니다. FAQ를 뒤질 필요가 없어요.

선택 · 사전준비자
카카오 알림톡 붙이기

등원·하원·미등원·데일리 리포트·월말평가서 링크를 학부모에게 자동 발송하려면 솔라피를 연결합니다. 사업자 인증 + 템플릿 검수(1~2영업일)가 필요해서, 준비되신 분만 후반부에 연결해요.

  • 솔라피 가입 → 카카오 비즈니스 채널 연동(pfId) → 발신번호 등록 → API 키/시크릿.
  • 템플릿 5종(등원/하원/미등원/데일리리포트/월말) 등록 → 검수 요청 → 승인되면 각 템플릿 ID 확보. 이전 세미나에서 등록한 템플릿은 그대로 재사용하시면 됩니다(1차=데일리리포트, 2차=나머지 4종).
  • Vercel 환경변수에 아래를 추가하고 재배포:
변수값
SOLAPI_API_KEY / SOLAPI_API_SECRET솔라피 API 키/시크릿
SOLAPI_SENDER등록한 발신번호
SOLAPI_PFID카카오 채널 pfId
TPL_CHECKIN / TPL_LATE / TPL_DAILY / TPL_REPORT템플릿 ID (등원 · 미등원 · 데일리리포트 · 월말평가서)
✓ 알림톡 없이도 완주 가능
솔라피를 안 넣으면 발송만 조용히 건너뛰고 출결·평가서·학부모 열람은 전부 정상입니다. 검수 대기가 병목이 안 돼요.
